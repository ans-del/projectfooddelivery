## 📖 About the Project

**MyOnlineMeal** is a front-end web development project created to practice and strengthen my understanding of HTML and CSS.

The project features a food delivery landing page for a fictional food service brand, with a visually appealing hero section, food service cards, a client showcase, and a contact form.

It focuses on building structured web layouts, styling page components, using Flexbox, implementing smooth navigation, and adapting the website for different screen sizes without relying on any CSS framework.

## ✨ Features

- 🧭 **Sticky Navigation Bar** – Easy navigation with a fixed-position menu.
- 🎯 **Hero Section** – Attractive landing section with background imagery and a call-to-action.
- 🥗 **Service Cards** – Dedicated sections highlighting different food services.
- 🤝 **Client Showcase** – Displays partner/client logos with a styled background.
- 📬 **Contact Section** – Contact form layout with input fields for user information.
- 🔗 **Smooth Scrolling** – Smooth navigation between page sections.
- 🎨 **Modern Styling** – Hover effects, background overlays, CSS variables, and custom typography.
- 📱 **Responsive Design** – Layout adjustments for smaller screens using CSS media queries.

## 🛠️ Built With

| Technology | Purpose |
|---|---|
| HTML5 | Page structure and semantic content |
| CSS3 | Styling, layouts, animations, and visual effects |
| Flexbox | Responsive alignment and component layouts |
| CSS Media Queries | Adapt layouts to different screen sizes |
| Google Fonts | Custom typography using Baloo Bhai 2 and Anton |
| Unsplash / Local Images | Visual assets and background imagery |

## 🚀 Getting Started

This project is built using HTML and CSS, so no installation of dependencies or build tools is required.

### 1. Clone the Repository

```bash
git clone https://github.com/ans-del/projectfooddelivery.git
```

### 2. Navigate to the Project Directory

```bash
cd projectfooddelivery
```

### 3. Run the Project

Open `index.html` directly in your web browser.

Alternatively, open the project in VS Code and use the Live Server extension for a better development experience.
